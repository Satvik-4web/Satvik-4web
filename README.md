## 🤖 AI / ML Project Showcase

### **Banknote Authentication via Multiple Classifiers**
* **Problem:** Detecting forged banknotes using wavelet variance, skewness, kurtosis, and image entropy.
* **Approach:** Processed statistical data extracted from images of genuine and forged banknote-like specimens.
* **Models Explored:** Implemented and compared various classification algorithms to find the optimal decision boundary.
* **Result:** A robust classification pipeline establishing a foundation for automated financial security screening.
* **Future Improvements:** Wrapping the best-performing model into a REST API (FastAPI) for real-time inference.
